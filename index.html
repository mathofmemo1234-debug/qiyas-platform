🔑 مفاتيح إعدادات مشروع Firebase

مجاني مدى الحياة (Spark)

انسخ مفاتيح تكوين تطبيق الويب من صفحة إعدادات مشروعك في Firebase Console وألصقها هنا، ثم اضغط حفظ ليتم تفعيل الاتصال والمزامنة فوراً.

🚀 أدوات المزامنة السحابية الفورية

بعد ربط مشروع Firebase، يمكنك نقل بنك الأسئلة ومزامنة حسابات الطلاب بنقرة زر واحدة.

📖 خطوات إنشاء قاعدة بيانات Firebase مجاناً (في دقيقتين):

  1. افتح وحدة تحكم Firebase: console.firebase.google.com وسجل بحساب Google.
  2. اضغط على «Add project» وسمّ المشروع (مثلاً: qiyas-training).
  3. من القائمة الجانبية اختر Build ➔ Firestore Database ثم اضغط Create database واضبط القواعد على Start in test mode.
  4. انتقل إلى Project Settings ⚙️ ثم انقر على أيقونة الويب </> وانسخ مفاتيح التكوين والصقها في النموذج هنا!
